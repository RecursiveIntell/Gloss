# Release Non-Goals

For the P34 repair pass, the following are explicit non-goals until a later pass implements and validates them with receipts:

- Cloud sharing, collaborative notebooks, mobile sync, or hosted accounts.
- Deep Research-style autonomous browsing.
- Realtime voice, realtime video, or live meeting capture.
- Audio overview/TTS generation.
- PDF/DOCX/XLSX/PPTX extraction beyond the current feature matrix.
- URL, YouTube, audio, and video ingestion beyond the current feature matrix.
- Studio reports, flashcards, quizzes, mind maps, and timelines as release-ready features.
- Notebook export/import portability.

Current runtime truth is maintained in `docs/CURRENT_FEATURE_MATRIX.md`.
