# Studio and Workspace Feature Spec

## RC scope

Only preserve notes and add Inspector Dock. Do not implement rich Studio outputs in RC unless trivial and gated.

## Broad Studio scope after RC

- source summaries;
- notebook report generation;
- flashcards;
- quizzes;
- timelines;
- mind maps;
- saved answers;
- output templates;
- evidence export;
- audio overview/TTS.

Every Studio artifact must include:

- source scope;
- prompt/generation receipt;
- citation/evidence support;
- export digest;
- degradation/fallback state.
